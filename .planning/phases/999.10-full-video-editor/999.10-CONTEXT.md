# Phase 999.10: Full In-Browser Video Editor - Context

**Gathered:** 2026-04-05
**Status:** Ready for planning

<domain>
## Phase Boundary

Editor de video completo integrado ao memeLab para edicao cena por cena do reel final. Timeline visual multi-track, preview ao vivo, edicao de legendas, customizacao de transicoes, configuracao de voz, e export server-side. Pagina dedicada acessivel apos a montagem do video.

</domain>

<decisions>
## Implementation Decisions

### Rendering engine
- **D-01:** Remotion como framework de rendering — cada cena e um componente React
- **D-02:** Remotion Player para preview ao vivo no browser (WYSIWYG)
- **D-03:** Export via Remotion CLI no backend (Node.js + Chrome headless) — resultado identico ao preview

### Timeline
- **D-04:** Multi-track: tracks separadas para video, audio e legendas
- **D-05:** Cenas como blocos arrastáveis na track de video
- **D-06:** Audio track mostra waveform
- **D-07:** Subtitles track mostra blocos de legenda com timing ajustável

### Interacao na timeline
- **D-08:** Drag centro do bloco = mover/reordenar cenas
- **D-09:** Drag bordas (handles) = trim duracao
- **D-10:** Right-click ou menu ••• = context menu (duplicar, deletar, split no playhead, alterar transicao)
- **D-11:** Scroll horizontal = navegar, pinch/scroll = zoom timeline

### Layout do editor
- **D-12:** Preview 9:16 centralizado no topo, timeline multi-track embaixo, painel de propriedades a direita (colapsavel)
- **D-13:** Toolbar no topo: play/pause, export, undo, redo
- **D-14:** Desktop only (>1024px) — mobile mostra mensagem "use desktop"

### Legendas
- **D-15:** Dual editing: timeline (ajustar timing via drag) + preview overlay (editar texto inline, mover posicao via drag)
- **D-16:** Painel lateral para estilo: fonte, cor, tamanho, sombra, posicao

### Regenerar por cena
- **D-17:** Seleciona cena na timeline, painel lateral mostra "Regenerar Narracao" e "Regenerar Clip"
- **D-18:** Durante regeneracao: spinner no bloco da timeline, preview continua com versao anterior
- **D-19:** Quando pronto: swapa automaticamente, timeline atualiza duracao

### Navegacao e data
- **D-20:** Nova rota `/reels/[id]/edit` — pagina dedicada fullscreen
- **D-21:** Botao "Editar Video" aparece no step final (video) e na lista de reels
- **D-22:** Carrega estado de `step_state` do reel (clips, audio, SRT, timings, script)
- **D-23:** Salva edicoes de volta em `step_state.editor`

### Persistencia
- **D-24:** Autosave debounced 2s apos cada acao — PATCH ao backend
- **D-25:** Indicador sutil "Salvando..." / "Salvo" (fade out)
- **D-26:** Sem botao salvar explicito

### MVP scope
- **D-27:** MVP inclui: timeline + reorder + trim, preview ao vivo, editor de legendas, config de voz por cena, transicoes custom, undo/redo
- **D-28:** Post-MVP: atalhos de teclado, audio mixing (volume, fade in/out)

### Claude's Discretion
- Lib de drag-and-drop (dnd-kit recomendado dado React 19)
- Implementacao do undo/redo (command pattern vs state snapshots)
- Waveform rendering approach (Web Audio API vs lib)
- Estrutura exata do `step_state.editor` schema
- Remotion composition structure e bundle setup

</decisions>

<specifics>
## Specific Ideas

- Referencia visual: VEED.io e CapCut web — layout e interacao similares
- Preview deve ser aspect ratio 9:16 (vertical reels) centralizado
- Timeline deve se sentir responsiva e fluida (framer-motion pra animacoes de drag)
- Regenerar cena nao deve travar o editor — continua editavel com versao anterior enquanto regenera
- Autosave deve ser invisivel ao usuario — sem friccao

</specifics>
