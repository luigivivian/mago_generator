## Decisions Made
- Zustand temporal (zundo) partializes only data state (scenes, subtitles, transitions, audioItems) -- UI state (selectedSceneId, playheadFrame) excluded from undo history to avoid jarring UX
- Scene transitions stored inline on EditorScene.transition rather than in separate EditorTransition[] array -- simpler mutations since transitions are per-scene properties
- genId uses Date.now + monotonic counter instead of uuid -- avoids adding another dependency for simple unique IDs
- @dnd-kit installed with --legacy-peer-deps due to React 19 peer dep mismatch (stable v6/v10 API)
