## Decisions Made
- Dynamic import with ssr:false for both @remotion/player Player and ReelComposition -- Remotion uses browser-only APIs (Canvas, WebCodecs) that crash in Node.js SSR
- inputProps wrapped in useMemo -- Remotion Player re-renders entire composition on prop change, memoization prevents render storm
- PlayerRef addEventListener("play"/"pause") for tracking playback state instead of controlled state -- matches Remotion recommended pattern
- Desktop gate at 1024px minimum width -- video editor requires horizontal space for 3-panel layout
