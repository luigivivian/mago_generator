- Modify `getThemes` to accept optional `character_slug`: `export const getThemes = (character_slug?: string) => request<ThemesResponse>("/themes" + (character_slug ? "?character_slug=" + character_slug : ""))`.
- Modify `getPublishingQueue` params to include `character_slug?: string`. Add to searchParams if set.
- Modify `getQueueSummary` to accept optional `character_slug`: append query param if set.
- Modify `getPublishingCalendar` to accept optional `character_slug` as third param. Append `&character_slug=` if set.
- Modify `getReelJobs` to accept optional `character_slug` as second param. Append to query string if set.
- Modify `getAdJobs` to accept optional `character_slug`. Append query param if set.
- Modify `getContentPackages` params to include `character_slug?: string`. Append if set.

**B. Add character_slug to SWR hooks** (use-api.ts):
For each hook, add `character_slug` to the function params AND to the cache key string.

- `useVideoGallery(params?)`: key becomes `video-gallery-${params?.character_slug ?? "all"}-${params?.status ?? ""}...`
- `useDriveImages(query?)`: key becomes `drive-images-${query?.character_slug ?? "all"}-${query?.theme ?? ""}...`
- `useThemes(character_slug?: string)`: key becomes `themes-${character_slug ?? "all"}`, fetcher passes `character_slug` to `api.getThemes(character_slug || undefined)`.
- `usePublishingQueue(params?)`: add `character_slug` to params type, key becomes `publishing-queue-${params?.character_slug ?? "all"}-...`
- `useQueueSummary(character_slug?: string)`: key becomes `queue-summary-${character_slug ?? "all"}`
- `usePublishingCalendar(start, end, character_slug?)`: key becomes `publishing-calendar-${character_slug ?? "all"}-${start}-${end}`
- `useContentPackages(limit, character_slug?)`: key becomes `content-packages-${character_slug ?? "all"}-${limit}`

- In use-reels.ts: `useReelJobs(status?, character_slug?)`: key becomes `reel-jobs-${character_slug ?? "all"}-${status ?? "all"}`. Fetcher: `api.getReelJobs(status, character_slug || undefined)`.

- In use-ads.ts: `useAdJobs(character_slug?: string)`: key becomes `ad-jobs-${character_slug ?? "all"}`. Fetcher: `api.getAdJobs(character_slug || undefined)`.

**IMPORTANT:** When `character_slug` is empty string or undefined, do NOT pass it to the API (results in no filter = all characters). Only pass when it has a truthy value (non-empty string).
