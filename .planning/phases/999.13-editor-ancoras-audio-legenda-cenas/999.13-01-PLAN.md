```ts
// 999.13 D-04: drift smoke-alarm. Subtitles load asynchronously
// (SRT fetch), so we defer the check to a microtask after both
// scenes and subtitles have settled.
queueMicrotask(() => {
  const state = get();
  if (state.scenes.length === 0 || state.subtitles.length === 0) return;
  const totalSceneSec = state.scenes.reduce((sum, s) => sum + s.durationInFrames, 0) / fps;
  const lastSubEnd = state.subtitles[state.subtitles.length - 1].endFrame / fps;
  const drift = Math.abs(totalSceneSec - lastSubEnd);
  if (drift > 0.5) {
    console.warn(
      `[editor:drift] sum(scene)=${totalSceneSec.toFixed(2)}s vs last_sub_end=${lastSubEnd.toFixed(2)}s (drift=${drift.toFixed(2)}s)`,
    );
  }
});
```

The microtask runs after `set()` but before any user interaction. The
SRT fetch is async via `.then`, so the check needs another tick to be
useful — actually since SRT loads asynchronously via promise, do a
`setTimeout(..., 1500)` instead so it fires after the fetch settles.
1.5s is generous enough to cover the SRT GET in any reasonable
network condition.
