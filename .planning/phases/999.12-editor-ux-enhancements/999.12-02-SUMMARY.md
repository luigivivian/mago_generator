# Plan 02 — Snap, nudge, auto-pause

## What landed

**lib/editor/snap.ts**: Pure `snapFrame(candidate, targets, ppf, threshold)`.
Converts the screen-space threshold to frame-space, returns nearest target
within range or the original candidate. No DOM, no React.

**TimelineBlock.tsx**: Added optional `snapTargets` prop. Each block type
applies snapping in its drag/trim handlers:
- VideoBlock right-trim: snaps the new absolute end frame against targets
  (excluding own start/end to avoid self-snap), respecting `blockStartFrame`
  for absolute math.
- SubtitleBlock left/right/move: snaps the absolute frame against targets.
- AudioBlock left/right/move: same pattern; right-trim translates
  candidate-end → duration after snap.
- All three honor `ev.altKey` to disable snapping during the drag (D-05).

**TimelineTrack.tsx**: Forwards `snapTargets` to every block. For the video
track, computes the cumulative absolute `blockStartFrame` for each scene
and passes it down — this is what lets video right-trim snap accurately
(scenes are laid out contiguously, not via absolute coordinates).

**Timeline.tsx**:
- New `snapTargets` memo: playhead frame + every scene start/end frame,
  recomputed when scenes or playhead change.
- Forwarded to all three TimelineTrack invocations.
- Extended the keyboard handler from Plan 01 with arrow-key nudging
  (D-06, D-07): `ArrowLeft`/`ArrowRight` ±1 frame, `Shift+Arrow` ±10,
  `Cmd/Ctrl+Arrow` ±30. Iterates `selection`, mutates subtitles and
  audio in a single `useEditorStore.setState` so the nudge is one undo
  entry. Scenes are intentionally not nudged (they live in a sortable
  list — moving them is reorder, not slide).

**SubtitleEditor.tsx**: Accepts `playerRef?: RefObject<PlayerRef>`.
Inside `handleMouseDown` of the SubtitleOverlay, if the player is
currently playing, calls `player.pause()` (D-08). Plumbed through from
the editor page.

**editor page**: Now passes `playerRef` to `<SubtitleEditor>`.

## How it satisfies the must-haves

- Snap fires within 6px (D-04) — `snapFrame` converts the px threshold
  via `pixelsPerFrame`, picks nearest target.
- Alt disables snap during drag (D-05) — handlers wrap snap call in
  `ev.altKey ? candidate : snapFrame(...)`.
- Arrow nudge by 1/10/30 frames (D-06) — keyboard handler reads modifier
  state, computes magnitude, applies to subtitles and audio in one
  `setState` for single-undo (D-07).
- Subtitle drag pauses player (D-08) — `handleMouseDown` calls
  `player.pause()` when `player.isPlaying()` is true.

## Notes

- Snap targets currently include playhead + scene boundaries. Could
  extend to subtitle/audio block edges in a follow-up if users want
  to snap subs to other subs.
- Did not write a snap unit test yet — can be added in a tests pass.
  The pure function is trivially testable: `snapFrame(100, [{frame:99}], 10, 6) === { frame: 99, snapped: true }`.
- Nudge magnitude `30` is a literal frame count for "1 second" at the
  current EDITOR_FPS=30. If FPS becomes configurable, this should
  reference EDITOR_FPS.
