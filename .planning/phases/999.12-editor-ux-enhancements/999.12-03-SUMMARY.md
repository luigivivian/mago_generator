# Plan 03 — Volume / mute / solo / zoom-to-fit

## What landed

**editor-types.ts**:
- `EditorAudioItem.volume?: number` (0..1, undefined = full)
- `export type TrackKind = "video" | "audio" | "subtitle"` formalized

**editor-store.ts**:
- New state: `mutedTracks: Set<TrackKind>`, `soloedTracks: Set<TrackKind>`
- `setAudioVolume(audioId, v)` clamps 0..1
- `toggleTrackMute(track)` flips set membership
- `toggleTrackSolo(track)` flips set membership AND clears mute on the
  same track when soloing (DAW convention)
- Both Sets excluded from temporal partialize (UI state, not document)

**PropertiesPanel.tsx**:
- New `AudioPanel` component with a 0-100% volume slider that calls
  `setAudioVolume(item.id, v/100)`
- Wired into `PropertiesPanel`: when only `selectedAudioId` is set
  (no scene/sub), render `<AudioPanel/>` instead of the empty fallback

**Timeline.tsx**:
- Track labels rewritten to a `[ "video", "audio", "subtitle" ].map`
  loop. Each row now has `M` and `S` letter buttons aligned right
  via `justify-between`. Buttons stop click propagation so they
  don't trigger the existing "select first item" handler.
- Active state visualized as `bg-yellow-500 text-zinc-900`
- Custom event listener `timeline:fit` calls `fitToView(totalFrames,
  scrollRef.current.clientWidth)` to handle the toolbar button.

**use-timeline-zoom.ts**:
- New `fitToView(totalFrames, viewportWidth)` clamps the computed
  `pixelsPerFrame` to the existing MIN/MAX bounds and resets scroll.

**Toolbar.tsx**:
- New `Maximize2` icon button between edit buttons and the save
  status indicator. Dispatches `window.dispatchEvent(new
  CustomEvent("timeline:fit"))` — keeps Toolbar decoupled from
  Timeline's DOM.

**ReelComposition.tsx**:
- Reads `mutedTracks`/`soloedTracks` from the editor store.
- `isAudibleTrack` rule: solo overrides mute; if any track is soloed,
  only soloed tracks play.
- Per-clip `<Audio volume={effectiveVolume} />` where
  `effectiveVolume = audioAudible ? (item.volume ?? 1) : 0`.
- `<SubtitleOverlay>` only renders when `subtitlesVisible`.

## How it satisfies the must-haves

- Per-clip volume in PropertiesPanel + applied in Remotion `<Audio>`
- M/S buttons in track labels, toggling sets via store actions
- Mute/solo respected by `ReelComposition` audibility rule
- "Fit" button → custom event → `fitToView` math
- Settings flow through autosave naturally because `volume` is part
  of `EditorPersistState` (it's a field on `EditorAudioItem` which
  is already persisted)

## Notes

- Subtitle track mute is implemented as overlay-hide in
  `ReelComposition`, not as a hidden track in the timeline UI itself.
  Could extend to hide the overlay editor too in a follow-up.
- Solo behavior is "additive solo" (multiple tracks can be soloed).
  DAW purists might prefer "exclusive solo" (one at a time). Easy
  toggle later if requested.
- `fitToView` uses the timeline's scroll element width — measures
  on the fly, no resize observer needed. If the user resizes the
  window without clicking Fit again, the fit becomes stale, which
  matches Premiere/Resolve behavior.
