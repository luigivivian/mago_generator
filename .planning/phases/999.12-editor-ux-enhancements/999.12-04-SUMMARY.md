# Plan 04 — Safe-zone overlay + resizable timeline panel

## What landed

**SafeZoneOverlay.tsx** (new):
- `useSafePlatform()` hook returns `[platform, setPlatform]` and
  persists in `localStorage["memelab.editor.safezone"]`
- `<SafeZoneOverlay platform>` renders three semi-transparent red
  zones (top, bottom, right) sized as fractions of the 1080×1920
  reference frame, scaled by parent dimensions.
- Pointer-events: none on every layer — never blocks the preview.
- Two preset platforms based on real CapCut overlays:
  - TikTok: top 220/1920, bottom 240/1920, right 80/1080
  - Instagram: top 130/1920, bottom 175/1920, right 70/1080

**edit/page.tsx**:
- Imports `SafeZoneOverlay` + `useSafePlatform`
- Calls hook in EditorPage component
- Renders overlay inside the preview container after `SubtitleEditor`
- Passes `safePlatform` and `setSafePlatform` to Toolbar

**Toolbar.tsx**:
- New `safePlatform` + `onSafePlatformChange` props (optional —
  Toolbar still works without them)
- New cycle button next to the Fit button. Cycle:
  off → tiktok → instagram → off
- Visual: `Smartphone` icon + a small "T" or "I" label when active
- Purple text when active so the user can tell at a glance

**EditorLayout.tsx**:
- New persistent `timelineHeight` state, default 220px
- Restore from `localStorage["memelab.editor.timelineHeight"]` on
  mount (clamped to viewport*0.6)
- New 4px-tall resize handle above the timeline panel:
  `bg-zinc-800 hover:bg-purple-500/40 cursor-row-resize`
- `handleResizeStart` registers pointermove/up listeners, computes
  `delta = startY - clientY` (drag up to grow), clamps to
  [180, viewport*0.6]
- Persists final height on pointerup; also has a backup useEffect
  that persists when state changes outside an active drag

## How it satisfies the must-haves

- Safe-zone overlay can be cycled and persisted (D-11, D-12)
- Overlay is `pointer-events: none` on every layer (D-12)
- Localstorage round-trip via `useSafePlatform` hook
- Timeline panel has a 4px draggable handle, clamped to
  [180px, viewport*0.6], persisted (D-18)

## Verification

- `npx tsc --noEmit` clean for the 4 modified/created files

## Notes

- The cycle button is simpler than a popover dropdown — picked it
  because the autonomous pass values speed and the user experience
  is fine for 3 states. A future iteration could use a Radix
  DropdownMenu with full labels.
- The CapCut numbers are approximations; users with platform-specific
  needs can fine-tune the constants in `SafeZoneOverlay.tsx` later.
- The resize handle uses native pointer events rather than
  `react-resizable-panels` — keeps the dependency tree small and the
  behavior easy to audit.
