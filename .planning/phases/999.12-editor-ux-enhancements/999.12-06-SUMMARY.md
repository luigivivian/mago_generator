# Plan 06 — Subtitle style presets

## What landed

**lib/editor/presets.ts** (new):
- `SubtitlePreset { id, name, style }` type
- `loadPresets()` / `savePresets(presets)` — localStorage round-trip
  with validation guards
- `addPreset(presets, style, name?)` — appends new entry, default name
  `Preset N`
- `renamePreset(presets, id, name)` — pure update
- `deletePreset(presets, id)` — pure filter
- All pure helpers (except load/save) — easy to test

**PropertiesPanel.tsx**:
- New `SubtitlePresetsSection` rendered after the Posicao section
  inside `SubtitlePanel`
- "Salvar estilo atual como preset" button captures the current
  subtitle style
- Saved presets shown as a list of clickable rows. Click to apply,
  double-click to rename inline (input swap), X button to delete
- Empty state copy when no presets exist
- Local React state for `presets` mirrors localStorage; `persist()`
  helper writes both at once

## How it satisfies the must-haves

- Save preset via button (D-21)
- Apply by clicking the row
- Rename via double-click → input swap → blur or Enter to commit,
  Escape to cancel
- Delete via X icon button
- All persisted in `memelab.editor.subtitlePresets` localStorage key

## Verification

- `npx tsc --noEmit` clean for the 3 modified/created files

## Notes

- No server sync — presets are personal taste, per the CONTEXT.md
  decision (D-22).
- Did not add a unit test for the pure preset helpers but they're
  straightforward to test if a future tests pass picks them up.
- The list uses double-click for rename rather than a dedicated
  "edit" button to keep the UI dense; the inline input has a tooltip
  hint via the title attribute.
