<objective>
Create a reusable AI prompt builder modal component and add scene prompt editing to the V2 regeneration flow. The modal provides structured fields (5W1H for Kling, narrative acts for Seedance) that assemble into a prompt string. On the detail page, users can edit scene prompts and regenerate with updated prompts.

Purpose: Users currently have no structured way to write video prompts. The 5W1H framework (from Kling prompt engineering guides) and Seedance narrative structure (from Seedance multishot skill file) produce higher-quality prompts than freeform text. Adding scene_prompts to regeneration enables iterative prompt refinement.

Output: PromptBuilderModal component, backend RegenerateV2Request extension, detail page scene prompt editing.
</objective>
