## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline padding |
| sm | 8px | Compact element spacing (`gap-2`, `py-2`) |
| md | 16px | Default element spacing (`space-y-4`, `p-4`) |
| lg | 24px | Section padding (`p-6` — CardHeader/CardContent) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Sub-theme pills: `px-3 py-1` (12px/4px) for compact touch targets — conforming values that provide adequate pill padding
- Duration slider thumb: 44px min touch target on mobile (native range input)

Note: the existing codebase uses `px-2.5` (10px) for sub-theme pills. Implementation must update this to `px-3` (12px) to conform to the spacing contract.

Source: existing codebase patterns (CardHeader `p-6`, CardContent `space-y-4`)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (normal) | 1.5 |
| Label | 12px (`text-xs`) | 400 (normal) | 1.5 |
| Heading | 18px (`text-lg`) | 600 (semibold) | 1.2 |
| Display | 24px (`text-2xl`) | 600 (semibold) | 1.2 |

Display is used for page-level headings only (e.g., "Criar Reel Interativo" page title). Heading is used for section titles within cards (e.g., "Configuracao Biblica" section heading). The 6px gap between 18px and 24px creates clear visual hierarchy separation.

Phase-specific additions:
- **Verse reference overlay** in script preview: 14px (`text-sm`) at weight 600 (semibold) in amber-400 (`#fbbf24`)
- **Scripture reference tag**: 12px (`text-xs`) at weight 400 in muted-foreground

Source: existing CardTitle `text-lg font-semibold`, body `text-sm`, labels `text-xs text-muted-foreground`

## Focal Point

**Primary screen:** When the user opens the reels wizard with `bible-stories` niche selected, the **BibleConfig section header ("Configuracao Biblica")** is the primary visual anchor. It appears below the sub-theme pills via `animate-fade-in`, drawing the user's eye to the biblical configuration fields that differentiate this niche from others.

**Secondary anchor:** The script mode toggle ("Gerar com IA" / "Roteiro Manual") is the first interactive element within BibleConfig and serves as the secondary visual anchor, guiding the user toward their first decision.

## Interaction Contracts

### Toggle: Script Mode (IA / Manual)

```
[ Gerar com IA ]  [ Roteiro Manual ]
```

- Two buttons side by side, mutually exclusive
- Active state: `bg-purple-500/20 text-purple-300 border-purple-500/40` (same as active sub-theme pill)
- Inactive state: `bg-secondary text-muted-foreground border-border`
- Default: IA selected
- When IA selected: show story selector + free text field
- When Manual selected: show textarea (8 rows)
- Transition: `transition-all duration-200`

### Select: Story Selector (IA mode)

- Standard `Select` component (Radix-based, already in project)
- Groups: "Antigo Testamento" header, then OT stories; "Novo Testamento" header, then NT stories
- Each item shows: story title + reference in muted text (e.g., "Davi e Golias — 1 Samuel 17")
- Below selector: Input field for free biblical reference with placeholder "Ex: Genesis 22, Parabola do semeador"
- Both are optional — user can pick from list OR type free reference OR both

### Slider: Duration (30-90s)

- Native HTML `<input type="range">` per Phase 999.4 decision (no Slider component)
- Range: min=30, max=90, step=5
- Default: 60 (when niche=bible-stories, overrides existing 30s default)
- Visual: `accent-purple-500` on the thumb (matches existing checkbox accent)
- Value label: `{value}s` displayed inline right of slider in `text-sm text-muted-foreground`
- Reset: when niche changes away from bible-stories, duration reverts to previous value

### Toggle: Include Reflection

- Labeled inline toggle: `[x] Incluir reflexao moderna`
- Uses native checkbox with `accent-purple-500` (same pattern as platform checkboxes in wizard)
- Default: checked (ON)
- When ON: script ends with 2-3 connecting sentences
- Label in `text-sm`, description in `text-xs text-muted-foreground`: "Adiciona reflexao conectando a historia com a vida atual"

### Verse Highlighting in Script Preview

- In `StepScript` component, when bible mode is active (detected from `step_state.config.bible_config`)
- Verse references rendered as: `<span className="text-amber-400 font-semibold">{verse_ref}</span>`
- Non-verse text renders normally in `text-foreground`
- Header shows verse count: `Badge` variant with amber color — "{n} versiculos citados"

### Conditional Field Appearance

- When user selects `bible-stories` niche in wizard:
  1. Sub-theme pills update to biblical stories (already existing behavior)
  2. BibleConfig section slides in below sub-themes with `animate-fade-in`
  3. Duration default changes to 60s
  4. Tone auto-sets to "inspiracional" (if not already)
- When user changes niche away from `bible-stories`:
  1. BibleConfig section disappears (no animation needed — instant unmount)
  2. Duration reverts to 30s
  3. Tone resets to previous value

### Loading States

- "Criar Reel Interativo" button shows `Loader2 animate-spin` during submission (existing pattern)
- Story selector: instant (data is frontend-static, no API call)
- Enhance suggestions: `Loader2 animate-spin` in "Sugerir Temas" button (existing pattern)

### Error States

- API failure on interactive reel creation: `text-sm text-red-400` inline error below buttons (existing pattern)
- Invalid bible reference (empty IA mode): form validation prevents submission — CTA button stays `disabled:opacity-50`
- Manual mode empty textarea: same validation, button disabled
