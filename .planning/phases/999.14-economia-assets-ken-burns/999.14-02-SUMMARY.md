# Plan 02 — Frontend toggle + cost preview + Ken Burns motion

## What landed

**api.ts**: `ReelsConfig` type extended with `economic_mode?: boolean`.
`saveReelsConfig` already accepts `Partial<ReelsConfig>` so the field
flows through automatically.

**reels-cost.ts** (new): Pure helper `estimateReelCredits({ targetDuration,
videoModel, economicMode })` returns `{ scenes, brl, credits, economic }`.
Approximation: dynamic mode ~3s/cena, economic mode ~6s/cena. Economic
mode zeros out the per-scene Kie cost (since it's bypassed). Mirrors
backend BRL constants (Hailuo Standard 1.31, Pro 6.30, Sora 2 8.50).

**reels/page.tsx**:
- ConfigPanel: new `economicMode` state, persisted via saveReelsConfig
- New labeled checkbox row "Modo economico (Ken Burns)" with description
  "Pula geracao de video Kie e usa imagens estaticas com zoom/pan no
  editor. Reduz custo em ~70%"
- Checkbox row gets emerald-tinted background when active
- Cost preview line in the create form (above buttons): shows scene
  count, BRL, credits. When economic mode is on, prepends an emerald
  "Modo economico" badge and shows the dynamic-mode price crossed out
  for comparison.

**Scene.tsx** (Remotion component):
- Wraps the `<Img>` branch in a transformed `AbsoluteFill`
- Uses `useCurrentFrame` and `interpolate` to compute:
  - `zoom = 1 → 1.15` over the full scene duration
  - `tx`/`ty` from a 4-pattern table indexed by `scene.index`:
    - 0: zoom-in center
    - 1: pan-left -5%
    - 2: pan-right +5%
    - 3: zoom-up -5%
- The clip branch (when `clipUrl` is set) is unchanged — only image-only
  scenes get Ken Burns. This means dynamic-mode reels with real Hailuo
  clips render normally; economic-mode reels get the motion automatically.

## How it satisfies the must-haves

- ConfigPanel checkbox persists via saveReelsConfig (D-02)
- Cost preview shows BRL + credits, dynamic vs economic comparison (D-09, D-10)
- Scene component applies subtle zoom + pan to image-only scenes (D-06, D-07, D-08)
- Coexists with dynamic mode: clips override Ken Burns (D-07)

## Notes

- Cost preview is approximate — TTS and image gen costs are not modeled
  because they're a small fixed component compared to the ~70% savings
  from skipping Hailuo. If users want exact numbers they can check the
  credit log after generation.
- The Ken Burns motion runs for the FULL scene duration, not just a
  portion. Felt more natural than easing in/out of motion.
- The 4-pattern table is index-based so a long economic reel doesn't
  feel monotone — pattern alternates every scene.
- Did not touch `bg-music-volume` or other adjacent fields — minimum
  surface area change.
